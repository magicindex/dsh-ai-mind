## v0.1.8 · AI 心流

本次更新统一标题栏「充值」按钮与余额胶囊的视觉。

### 变更

- **充值按钮配色**：改用与余额胶囊相同的底色、描边与字重，悬停态统一为强调色描边 + 淡色底；两者并排时成为一组，不再单独抢眼。
- **亮色主题同步**：亮色下充值按钮与余额胶囊共用同一组白底与阴影。
- **兼容**：尺寸、位置、跳转行为（新窗口打开 DeepSeek 充值中心）与余额只读逻辑均不变。

### 安装

```bash
curl -L -o dsh-ai-mind-0.1.8-fnos-release.zip \
  https://github.com/magicindex/dsh-ai-mind/releases/download/v0.1.8/dsh-ai-mind-0.1.8-fnos-release.zip
unzip dsh-ai-mind-0.1.8-fnos-release.zip
cd dsh-ai-mind-0.1.8
chmod +x install.sh
./install.sh web
```

已安装 `dsh-better-sidebar >= 0.26.0` 时，也可只装 `dsh-ai-mind-0.1.8.tgz`。

### 校验

见 `SHA256SUMS` 附件。
