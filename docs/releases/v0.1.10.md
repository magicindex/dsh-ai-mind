## v0.1.10 · AI 心流

本版把安装流程收成一条命令，并补齐 Gitea 上的发布包。插件功能与 0.1.9 完全相同，`lib/client.js` 无变化。

### 新增

- **一键安装**：仓库根目录新增 `install.sh`。一条命令完成下载完整发布包、`SHA256SUMS` 校验、解压、安装依赖与插件，并自动清理临时目录。
- **双源支持**：默认从 Gitea 下载，`AIM_MIRROR=github` 可切换到 GitHub；`AIM_VERSION` 可指定版本。
- **避免降级**：发布包内的 `install.sh` 会检测 `dsh-better-sidebar`，已安装时跳过自带的 0.26.0，避免把用户的较新版本降级。
- **README 重写**：下载区同时给出 GitHub / Gitea 直链；安装区以当前版本的一键命令为默认方式，保留完整包手动安装、纯插件包和源码安装。

### 一键安装

```bash
curl -fsSL https://gitea.topzero.cn:10241/cyberzero/dsh-ai-mind/raw/branch/main/install.sh | bash -s -- web
```

GitHub 源：

```bash
curl -fsSL https://raw.githubusercontent.com/magicindex/dsh-ai-mind/main/install.sh | bash -s -- web
```

profile 不叫 `web` 时替换最后的参数。安装完成后重启 `dsh web`。

### 下载

- 完整发布包：`dsh-ai-mind-0.1.10-fnos-release.zip`
- 纯插件包：`dsh-ai-mind-0.1.10.tgz`
- 校验：`SHA256SUMS`

### 兼容性

- DSH `0.2.0-rc.2` 左右版本
- `dsh-better-sidebar >= 0.26.0`
- 无插件行为变更，已装 0.1.9 的用户可按需升级
