## v0.1.9 · AI 心流

本版只更新文档与打包版本号，插件功能与 0.1.8 完全相同。

### 变更

- **新增排查说明**：左侧会话列表出现长标题换行、时间与操作按钮掉到第二行时，如何确认是 DSH 客户端模块加载器把其他插件未打标的 `<style>` 认领并删除，以及 `claimStyles` 的修复写法。
- **README 更新**：下载链接、安装命令、打包示例、版本号统一到 0.1.9；预览说明补充充值入口。
- **无行为变更**：`lib/client.js` 与 0.1.8 一致，已装 0.1.8 的用户无需为此升级。

### 安装

```bash
curl -L -o dsh-ai-mind-0.1.9-fnos-release.zip \
  https://github.com/magicindex/dsh-ai-mind/releases/download/v0.1.9/dsh-ai-mind-0.1.9-fnos-release.zip
unzip dsh-ai-mind-0.1.9-fnos-release.zip
cd dsh-ai-mind-0.1.9
chmod +x install.sh
./install.sh web
```

已安装 `dsh-better-sidebar >= 0.26.0` 时，也可只装 `dsh-ai-mind-0.1.9.tgz`。

### 校验

见 `SHA256SUMS` 附件。
