## v0.1.7 · AI 心流

本次更新重做标题栏的充值入口：充值与余额拆开，充值改为按钮。

### 变更

- **充值按钮**：标题栏余额区拆成「充值 \ 余额」；「充值」改为强调色描边 + 淡底的按钮，点击在新窗口打开 DeepSeek 充值中心。
- **余额只读**：余额胶囊只展示金额，不再整块可点；悬停仍显示查询时间与充值入口提示。
- **兼容**：亮 / 暗色主题、窄面板自适应、余额不足警示色保持不变。

### 安装

```bash
curl -L -o dsh-ai-mind-0.1.7-fnos-release.zip \
  https://github.com/magicindex/dsh-ai-mind/releases/download/v0.1.7/dsh-ai-mind-0.1.7-fnos-release.zip
unzip dsh-ai-mind-0.1.7-fnos-release.zip
cd dsh-ai-mind-0.1.7
chmod +x install.sh
./install.sh web
```

已安装 `dsh-better-sidebar >= 0.26.0` 时，也可只装 `dsh-ai-mind-0.1.7.tgz`。

见 `SHA256SUMS` 附件。
