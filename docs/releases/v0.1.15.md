## v0.1.15 · AI 心流

本版移除了已失效的自建镜像源，下载与安装统一走 GitHub，并重新打包全部发布产物。

### 变更

- **移除自建镜像源**：原自建镜像实例与其内网地址已下线，README、发布说明与 `install.sh` 中不再出现镜像地址。
- **安装脚本单源化**：`install.sh` 去掉 `AIM_MIRROR` 双源开关，固定从 GitHub Releases 取包；`AIM_VERSION` 仍可指定版本。
- **重新打包**：`dsh-ai-mind-0.1.15.tgz` 与完整发布包 zip 重新生成，包内 README 与 `install.sh` 同步为不含镜像地址的版本，`SHA256SUMS` 一并更新。
- **文档**：README 下载区只保留 GitHub 直链；常见问题补充 `curl -4` 的排查说明（网络 IPv6 不可用时 `raw.githubusercontent.com` 可能超时）。
- **无插件行为变更**：面板界面与功能与 0.1.14 一致，`lib/client.js` 仅版本号常量变化。

### 一键安装

```bash
curl -fsSL https://raw.githubusercontent.com/magicindex/dsh-ai-mind/main/install.sh | bash -s -- web
```

profile 不叫 `web` 时替换最后的参数。安装完成后重启 `dsh web`。

### 下载

- 完整发布包：`dsh-ai-mind-0.1.15-fnos-release.zip`
- 纯插件包：`dsh-ai-mind-0.1.15.tgz`
- 校验：`SHA256SUMS`

### 兼容性

- DSH `0.2.1-rc.5`（0.2.0-rc.2、0.2.2-rc.1 同样覆盖，见 README「版本对应关系」）
- `dsh-better-sidebar >= 0.26.0`（0.2.1 一代建议 0.28.x）
- 已装 0.1.14 的用户可直接升级，界面与设置不变
